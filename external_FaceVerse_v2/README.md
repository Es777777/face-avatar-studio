# FaceVerse V2 Model

Place the optional official FaceVerse V2 model here:

```text
data/faceverse_simple_v2.npy
```

Official project and download instructions:

<https://github.com/LizhenWangT/FaceVerse#faceverse-version-2>

When the file is absent, Face Avatar Studio uses the 52D ARKit-compatible
bases in the bundled FaceVerse V4 full-head asset. The application status bar
identifies the active source instead of silently presenting compatibility mode
as the official V2 mesh.

The FaceVerse model, code, and data remain subject to the upstream FaceVerse
license and usage terms.
